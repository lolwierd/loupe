loupe for GitHub

Address

loupe answers at loupe.local and at 127.0.0.1:4500. l.local only redirects, so it is saved as loupe.local. Check asks once for access to the address, to read loupe's state.

Shortcut

Opening on its own

Where

Owners or owner/repo, separated by commas or spaces. Empty means every pull request.

A pull request you open in loupe yourself, then follow to GitHub, is sent back to loupe once, unless the extension can see loupe's tabs.

Also

  • The toolbar button opens the current tab's pull request in loupe, or loupe at its root.
  • Right-click a link to a pull request, on any page, for Open link in loupe.
